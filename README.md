# 🛍️ ShopSmart AI – E-Commerce Assistant

An AI-powered e-commerce assistant that compares product prices across online marketplaces in real time and recommends the best deal with intelligent, context-aware add-ons.

## ❓ Why Use ShopSmart AI?

Online shopping platforms often show a wide range of prices for the same product, making it difficult for users to identify the best deal quickly. ShopSmart AI addresses this issue by:

* Automatically comparing product prices across multiple marketplaces
* Recommending the best-value option based on availability and cost
* Suggesting relevant add-ons without category drift
* Providing a streamlined and intuitive user interface
* Storing previous searches for quick re-evaluation

This helps users make faster, smarter, and more cost-effective purchasing decisions without manually browsing multiple websites.

## ✨ Key Features

---

## 🧩 How It Works

1. The user logs in and searches for a product.
2. The app fetches live shopping results via the Serper API.
3. The AI module analyzes price and availability to recommend the best option.
4. Add-ons are generated by anchoring them to the original query to maintain relevance.
5. Results are displayed as responsive product cards.
6. Search history is stored in SQLite for future reuse.

```

```
